======================================================================
  EmbedKit - Production Embedding Pipeline Toolkit
======================================================================

Author: Maharshi Soni
Category: vector-search
Difficulty: advanced

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
A pip-installable toolkit for building embedding pipelines. Multiple chunking strategies, embedding generation with caching, unified vector store interface supporting FAISS and in-memory backends.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - sentence-transformers
  - faiss-cpu
  - numpy
  - click
  - pydantic
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * Multiple chunking strategies
  * Embedding generation with disk caching
  * Vector store abstraction: FAISS and in-memory
  * Hybrid search: vector + BM25
  * CLI tool for indexing and querying

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  Documents to index and search

  Example:
    embedkit index --input docs/ --store my_index

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Search results with similarity scores

  Example:
    embedkit search --query 'machine learning' --top-k 5
